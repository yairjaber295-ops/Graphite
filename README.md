# Graphite

Видеоредактор для нарезок, эдитов и Shorts/TikTok: нарезка длинного видео на части, субтитры, заголовки, обложки,
эффекты и переходы, эдиты под бит, ремиксы музыки, реклама-вставки, улучшение качества нейросетью.
Работает на компе (Windows) и на телефоне (Android), проекты можно открывать с телефона по Wi-Fi.

## Скачать

Раздел **[Releases](../../releases)**:

- `Graphite-win64.zip` — программа для Windows 10/11 (64-бит). Распакуй и запусти `Graphite.exe`.
  Python и библиотеки ставить не нужно — всё внутри.
- `Graphite.apk` — приложение для Android.

При первом запуске Windows может показать «Система Windows защитила ваш компьютер» (программа без цифровой подписи):
**Подробнее → Выполнить в любом случае**.

## Что умеет

- **Нарезка на части** с заголовками «Часть N», обложками и выгрузкой серий; планировщик выкладки в TikTok.
- **Субтитры** (Whisper, офлайн): при первом распознавании скачивается модель ~1.5 ГБ.
  На видеокарте NVIDIA с установленным CUDA 12 — быстро, без неё — на процессоре.
- **Эффекты, переходы, анимации текста**, хромакей, стоп-кадр, растяг, скорость, кривые скорости.
- **Звук**: замедление/ускорение, slowed + reverb, ремиксы (хардтек, джерси, фонк…), бас, эквалайзер.
- **✨ Улучшить качество** (Real-ESRGAN на видеокарте): быстрая лёгкая модель, качественная x4plus или без ИИ,
  разрешение до 4K, предпросмотр кадра со шторкой «до/после».
- **Темы оформления**, в том числе «Карбон».

## Требования

- Windows 10/11 x64. Окно работает на WebView2 — в Windows 11 он уже есть, в Windows 10 ставится
  с [сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/), если окно не открывается.
- Для улучшения качества нужна видеокарта с Vulkan (NVIDIA / AMD / Intel), для быстрых субтитров — NVIDIA + CUDA 12.

Данные программы (проекты, настройки) лежат в `%LOCALAPPDATA%\Graphite`, готовые видео — в `Видео\Graphite`
(папку можно поменять: `"work_dir"` в `settings.json`).

## Запуск из исходников

Нужен Python 3.10+ («Add Python to PATH» при установке):

1. `Установить.bat` — поставит библиотеки и ярлык;
2. `python tools/get_esrgan.py` — нейросеть для «Улучшить качество» (~45 МБ);
3. `Запустить.bat` или ярлык Graphite.

## Сборка

- `tools/build_release.ps1` — самостоятельная сборка для Windows (`release/Graphite-win64.zip`, нужен `pip install pyinstaller`).
- `tools/build_android.ps1` — Android-приложение (скачает Java и Android SDK при первом запуске).

## 🌟 Ключевые возможности

### 🚀 Аппаратный движок нового поколения
- **Сверхбыстрый экспорт**: декодирование и кодирование через **WebCodecs + WebGL2** прямо на GPU (~3× быстрее реального времени на видеокартах NVIDIA RTX).
- **Pixel-Perfect WYSIWYG**: превью и рендер используют идентичный пайплайн — что видишь на таймлайне, ровно то и сохраняется в MP4.

### 🤖 Автоматизация в 1 клик
- **Локальные субтитры (Whisper)**: точная расшифровка речи без отправки данных в облако (на базе `faster-whisper`).
- **Авторазбивка на части**: умный алгоритм делит длинный ролик по паузам и границам предложений на серии оптимальной длины.
- **Оформление серий**: автогенерация номеров частей (`(часть 1)`, `(часть 2)`, `(финал)`), стильные обложки для социальных сетей (первый кадр + `.jpg` для превью).
- **Автоэдит под бит**: алгоритмический монтаж нарезки моментов под ритмическую сетку трека с акцентами и вспышками.

### 🎨 Эффекты и переходы
- **45 шейдерных эффектов** (с живым превью при наведении):
  - *Тряска (14)*: обычная, ручная камера, удар, землетрясение, бас-тряска, дрожь, зум-удар, дрейф...
  - *Свет и цвет*: стробоскоп, вспышки, свечение, затемнение, неон.
  - *Искажения*: глитч, RGB-сплит, калейдоскоп, рыбий глаз, волна, радиальный блюр.
  - *Стилизация*: VHS, CRT-телевизор, ретро-плёнка, Ч/Б, негатив, кино-полосы.
  - *Комбо в 1 клик*: Бит-дроп, Ярость, Флешбэк, Эпичный момент, Ретро-ТВ.
- **44 динамических перехода**: рывки, вращения, 3D-куб, шторки (круг, затвор, сердце), RGB-разлом, зум-блюр. Функция «Случайные на все стыки».
- **Анимации текста**: кинетическая печатная машинка (со звуками клавиш под буквы), неон, маятник, пульсация.

### 🎵 Профессиональная работа со звуком
- **Алгоритм WSOLA**: изменение скорости клипов (0.1× – 10×) с сохранением оригинальной высоты тона (pitch).
- **Кривые скорости**: Монтаж, Герой, Пуля, Прыжок, Разгон, Торможение.
- Отделение звуковой дорожки от видео в один клик.

### 📱 Работа с телефона и ПК (Синхронизация по Wi-Fi)
- Редактор работает как автономное нативное окно Windows (`WebView2`), так и на телефоне (PWA / Android).
- При нахождении в одной Wi-Fi сети телефон использует вычислительную мощность ПК для создания субтитров Whisper и рендера.

## 🛠 Быстрый старт

### Требования
- **ОС**: Windows 10/11 (или Linux/macOS в режиме сервера)
- **Python**: 3.10 или новее
- Рекомендуется дискретная видеокарта для аппаратного ускорения WebCodecs.

### Установка и запуск

#### Вариант А: Быстрый запуск на Windows (в 1 клик)
1. Скачайте репозиторий архивом (или клонируйте: `git clone https://github.com/your-username/Graphite.git`).
2. Запустите двойным кликом **`Установить.bat`** — он сам установит нужные библиотеки и настроит ярлык в меню «Пуск».
3. Запускайте редактор через созданный ярлык, через **`Graphite.exe`** или файл **`Запустить.bat`** (без лишних окон консоли).

#### Вариант Б: Через терминал
```bash
git clone https://github.com/your-username/Graphite.git
cd Graphite
pip install -r requirements.txt
python app/desktop.py
```

## ⚙️ Настройки путей

По умолчанию готовые нарезки сохраняются в папку `Видео/Graphite` в профиле пользователя.

Вы можете переопределить папку экспорта:
- Через переменную окружения:
  ```bash
  set GRAPHITE_WORK_DIR=E:\MyVideos\Exports
  ```
- Либо в файле `settings.json` в корне программы:
  ```json
  {
    "work_dir": "E:\\MyVideos\\Exports"
  }
  ```

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | Воспроизведение / Пауза |
| `J` / `K` / `L` | Перемотка назад / Стоп / Перемотка вперёд |

| `M` | Добавить маркер на таймлайн |
| `Shift + Клик` | Множественное выделение клипов |

## 🏗 Архитектура

- **Frontend**: ES-модули без тяжёлых фреймворков. Рендерер — собственный WebGL2-композитор + библиотека `mediabunny`.
- **Backend**: Легковесный асинхронный HTTP/WebSocket сервер на стандартной библиотеке Python + `pywebview`.
- **Нейросети**: `faster-whisper` (CTranslate2) для сверхбыстрой транскрибации речи.
- **Шрифты**: 50+ встроенных открытых шрифтов с поддержкой кириллицы (Rubik, Montserrat, Dela Gothic и др.).
